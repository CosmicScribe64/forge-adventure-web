# raw/

Drop new sources here: clipped articles (TeaVM / gdx-teavm docs, blog posts), upstream issue
threads, session transcripts, screenshots, benchmark outputs. Then ask Claude to "ingest raw/<file>".

The LLM reads files here and never edits them. The project's own NOTES.md, PLAN.md, patch and
code are also sources, but they stay where they are.

Suggested: in Obsidian, set Settings → Files and links → Attachment folder path to `raw/assets`.
